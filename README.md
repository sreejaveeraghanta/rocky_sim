# Rocky Simulator

A 3D simulation of Rocky built using Rust and Bevy

## Goals

- Simulate Rocky, a five legged creature
- Implement procedural locomotion
- Simulate joints and body physics
- Implement environmental interaction
- Explore autonomous creature behaviour
- Simulate musical communication


## Technology
- Rust
- Bevy
- Blender? (for 3D assets)


## Run Simulator
```
cargo run
```

## Run Tests
```
cargo test
```
